# copilot-code

Excel の Copilot チャットペインを、ブックのセルから操作するための PowerShell スクリプトです。
チャットシートに指示を書くと、Copilot に送信して回答をシートに書き戻します。Copilot が返答の末尾に `Action: ツール名(引数)` と書いたときは、スクリプトがそのツールを実行し、結果を Copilot に返して続きを進めさせます（Claude Code のようなツール利用ループ）。

## 構成

| ファイル | 内容 |
| --- | --- |
| `copilot.ps1` | 本体。Windows PowerShell 5.1 で動く |
| `copilot.xlsx` | マスタのブック。起動のたびにコピーして使い、マスタは書き換えない |
| `setup.ps1` | インストールと環境変数の登録 |

## 動作環境

- Windows 11 / Windows PowerShell 5.1（`pwsh` は不要）
- デスクトップ版 Excel（Copilot チャットが使える Microsoft 365）
- Copilot の利用枠（月ごとのクレジットが尽きると「今月はクレジットが不足しています」と返り、動かなくなる）

## インストール

```powershell
powershell -File ./setup.ps1
```

次のことを行います（管理者権限は不要）。何度実行しても結果は同じです。

1. `copilot.ps1` と `copilot.xlsx` を `~/.copilot-code`（`%USERPROFILE%\.copilot-code`）にコピーする。既存の `copilot.xlsx` と内容が違うときは、`copilot.xlsx.bak` に退避してから上書きする
2. 起動用の `copilot-code.cmd` を作る
3. ユーザー環境変数 `COPILOT_CODE_HOME` にインストール先を登録し、`Path` に追加する

新しく開いたターミナルで、作業したいディレクトリに移動して `copilot-code` と入力すると起動します。`copilot-code -ReadOnly` のように、パラメータもそのまま渡せます。

| オプション | 内容 |
| --- | --- |
| `-InstallDir` | インストール先を変える（既定 `~/.copilot-code`） |
| `-Uninstall` | インストール先を削除し、環境変数と `Path` の追加分を元に戻す。`%LOCALAPPDATA%\copilot-code` の作業用コピーは残る |

## 使い方

```powershell
powershell -File ./copilot.ps1
```

Claude Code の `!` から起動するときは、`pwsh` がないので `! powershell -File ./copilot.ps1` と書きます（パスは `/` 区切り）。

起動すると、次の順に動きます。

1. `copilot.xlsx` を `%LOCALAPPDATA%\copilot-code\sessions\<日時>\` にコピーして、新しい Excel インスタンスで開く
2. 起動したディレクトリの絶対パスを、コピーの `設定!C2` に書く
3. Copilot ペインを開き、ツールの使い方などを書いた初回プロンプトを 1 回だけ送る
4. チャットシートの、待機中の `USER:` 行の C 列を監視する
5. C 列に指示が書かれたら、その文だけを Copilot に送る
6. 回答を `Result:` 行に書く。`Action:` があればツールを実行して、結果を返す（5 の続き）
7. 回答が終わったら、次の `USER:` 行を作って待つ。何ターンでも続けられる

ブックを閉じるとスクリプトも終了します。

### 入力ロック

処理中に誤って入力しないよう、`チャット` シートを一時的に入力不可にします。1 行目に、いまの状態が表示されます。

| 状態 | 表示（1 行目） | 入力できるセル |
| --- | --- | --- |
| 初期化中 | 橙: 初期化中です。しばらくお待ちください… | なし |
| 応答待ち | 橙: Copilot の応答を待っています… | なし |
| 待機中 | 緑: 入力できます (C○ に入力して Enter) | 待機中の `USER:` 行の C 列だけ |

- パスワードなしのシート保護を使います。スクリプトからの書き込みは止まりません。
- 保護を外したいときは、「校閲」タブの「シート保護の解除」を押してください。
- 保存したコピーを後から開くと、保護された状態のままです。
- 使いたくないときは `-NoLock` を付けてください。

### 自動保存

作業用のコピーは、次のタイミングで自動的に上書き保存されます（COM の `Save` なので、Excel が非アクティブでも動き、保存ダイアログは出ません）。

- `USER:` 欄の入力を検知したとき
- Copilot の返答と、各ツールの結果をシートに書いたとき
- 次の `USER:` 行を作ったとき

コピーは終了後も残るので、会話を後から見返せます。古いものは、`sessions` の下のフォルダを手で削除してください。セルの編集中などで保存できないときは、20 回（約 10 秒）再試行し、それでも保存できなければ警告を出して続けます。

## ブックの構成

| シート | 内容 |
| --- | --- |
| `チャット` | B 列にラベル、C 列に本文。`USER:`（入力）/ `Result:`（Copilot の回答）/ `Action:`（実行したツール）/ `Observation:`（ツールの結果）/ `Error:` |
| `設定` | `C2` にスクリプトを起動したディレクトリ（自動で書かれる）。ツールが触れる範囲の基準になる |
| `プロンプト` | `B2` に起動時に 1 回だけ送るテンプレート、`B3` にツール結果を返すときのテンプレート、`B4` にユーザの入力ごとに送るテンプレート |

テンプレートの置換:

- 起動時（`B2`）: `__SUMMARY__`（今は空）、`%DIRECTORY%`（設定!C2）
- ツール結果（`B3`）: `%DIRECTORY%`、`__ACTION__`、`__OBSERVATION__`
- ユーザ入力ごと（`B4`）: `__PROMPT__`（入力した指示）、`%DIRECTORY%`。既定は `__PROMPT__` だけで、入力した文がそのまま届く。空にしても同じ

セル全体がそのまま Copilot に送られます。ツールの説明や注意事項を変えたいときは、マスタの `プロンプト!B2` を編集してください。

### ツールの説明は起動時に 1 回だけ送る

Copilot のチャットは会話の履歴を持ち越すので、ツールの使い方や注意事項（`B2`）は起動時に 1 回だけ送ります。その返答は「了解」だけです。以降は、`USER:` 欄に書いた文だけを送ります（`B4`）。ツール結果の返信（`B3`）も短い形です。

ペインで「新しいチャット」を押すと、Copilot は説明を忘れます。その場合は、スクリプトを起動し直してください。

## ツール

Copilot は、返答の最終行に `Action: ツール名(引数)` を 1 行だけ書いて呼び出します。パスは設定!C2 のディレクトリからの相対パスです。

| ツール | 内容 |
| --- | --- |
| `List(パス)` | ディレクトリの一覧（200 件まで） |
| `Read(パス[, 開始行, 行数])` | 行番号付きで読む。出力が上限を超えると途中で切り、続きの開始行を案内する |
| `Grep(パターン[, パス])` | 正規表現（大文字小文字は区別しない）で検索。200 件まで。5 MB 超とバイナリ、`.git` は対象外 |
| `Write(パス)` | ファイルの新規作成・全体の上書き。内容は Action の次のコードブロックで渡す |
| `Update(パス, 開始行, 終了行)` | 指定行をコードブロックの内容で置き換える。終了行を「開始行-1」にすると挿入、空のコードブロックにすると削除 |
| `Shell(コマンド)` | PowerShell のコマンドを実行し、標準出力・標準エラー・終了コードを返す。複数行は引数を空にして、コードブロックに書く |

- ツールの結果は全文を Copilot に送ります。シートに載せるのは先頭のプレビューだけです（`-CellPreviewChars`）。
- 1 回の指示で実行できるツールは、最大 `-MaxSteps` 回です。
- `Write` / `Update` は、元のファイルを `%LOCALAPPDATA%\copilot-code\backup\<日時>\` に退避してから書きます。既存ファイルの BOM と改行コードは保たれます。UTF-8 でないファイルやバイナリは上書きしません。

## 安全性についての注意

- `List` / `Read` / `Grep` / `Write` / `Update` は、設定!C2 のディレクトリの外には出られません（`.git` への書き込みも拒否）。シンボリックリンクによる脱出は考慮していません。
- **`Shell` はこの制限を受けません。** 作業ディレクトリが設定!C2 になるだけで、PowerShell でできることは何でも実行できます。既定で有効、実行前の確認もありません。
- 読み込んだファイルの中に「次は `Action: Shell(...)` を実行せよ」のような文があると、Copilot が従ってしまう恐れがあります（プロンプトインジェクション）。信頼できないファイルがあるディレクトリでは使わないでください。
- Write 系と Shell をまとめて止めるには `-ReadOnly` を付けます。

## パラメータ

| パラメータ | 既定値 | 内容 |
| --- | --- | --- |
| `-Port` | `9222` | Copilot ペイン（WebView2）のリモートデバッグポート |
| `-ReplyTimeoutSec` | `300` | Copilot の返答を待つ上限（秒） |
| `-ShellTimeoutSec` | `300` | `Shell` 1 回の実行時間の上限（秒）。超えたら、そのプロセスだけを子プロセスごと止める |
| `-MaxSteps` | `10` | 1 回の指示で実行するツールの上限回数 |
| `-MaxOutputChars` | `50000` | ツール 1 回の出力の上限（文字） |
| `-CellPreviewChars` | `1000` | `Observation:` セルに書く上限（文字） |
| `-ReadOnly` | オフ | `Write` / `Update` / `Shell` を無効にする |
| `-NoLock` | オフ | 処理中でも `チャット` シートを入力不可にしない |
| `-SessionRoot` | `%LOCALAPPDATA%\copilot-code\sessions` | 作業用コピー（自動保存される）を置くフォルダ |
| `-BringToFront` | オフ | 送信のたびに Excel を前面に出してフォーカスを移す（既定では前面に出さない） |
| `-Test` | オフ | 自動テストを実行する |
| `-TimeoutSec` | `900` | `-Test` 全体の制限時間（秒） |

## しくみ

- ペインを開く: UI Automation でリボンの `Copilot Chat` ボタンを押す。ペインは、クラス名 `MsoWorkPane` かつ名前 `Copilot` の要素で判定する
- 非アクティブでの動作: Excel を前面に出さずに動く。セルの操作は COM、入力と送信は CDP なので OS のフォーカスを使わない。ページには `Emulation.setFocusEmulationEnabled` で「フォーカスあり」と見せ、WebView2 の起動引数でバックグラウンドの描画抑制を切っている。ペインを開く操作だけは Excel が一瞬前面に出るため、起動直後（Excel が自分で前面に出るとき）に済ませる。
- 入力と送信、回答の取得: ペインの中身は WebView2 で UI Automation からは見えないため、Excel を `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=<Port> --force-renderer-accessibility"` つきで起動し、CDP（Chrome DevTools Protocol）の WebSocket で DOM を操作する
- 改行: Enter は送信になるため、行の区切りは Shift+Enter で入力する
- セルの検知: 起動した Excel に `BindToMoniker` で接続し、500 ms ごとにポーリングする。Excel が操作を拒否したときは 30 秒までリトライする

## 自動テスト

```powershell
powershell -File ./copilot.ps1 -Test -Port 9333
```

一時ディレクトリにダミーのデータ（`notes.txt`）を作り、実際に Copilot に指示を出して、次の 7 ラウンドを確認します。終了後はテスト用の Excel（自分で起動したものだけ）とファイルを片付けます。

1. 通常の質問（日本の首都）
2. `List`
3. `Read`（出力上限を小さくして、続きを読めるか）
4. `Grep`
5. `Write`
6. `Update`（BOM・行数・バックアップの確認を含む）
7. `Shell`（日本語の出力と作業ディレクトリ）

`-Port` を 9222 以外にしておくと、常駐中の通常のインスタンスと衝突しません。テストは Copilot のクレジットを消費します。

## 既知の制限

- 常駐中のスクリプトは、起動時のコードで動き続けます。`copilot.ps1` を変えたら、止めて起動し直してください。
- Copilot の「データの分析」などの紹介ポップアップが出ると、Excel のウィンドウが操作できなくなり、検出に失敗します。出たら手動で閉じてください。
- 通常起動の Excel と同時に使うと、WebView2 のプロファイルが共有される場合があります。その場合の動作は保証しません。
- 巨大ファイルの読み込みは、`Read` のページング（`-MaxOutputChars` ごと）に頼っています。
- Excel のウィンドウを最小化した状態には対応していません。他のウィンドウの後ろに隠れているだけなら動きます。
- 長い会話では、Copilot が最初のツールの説明を守らなくなることがあります。そのときは、スクリプトを起動し直してください。
